# راهنمای Demo Mode

## وضعیت پیش‌فرض

demo mode در نسخهٔ production باید **غیرفعال** باشد. React فقط زمانی داده‌های ساختگی و `localStorage` را برای رفتارهای demo استفاده می‌کند که متغیر زیر دقیقاً روی `true` قرار گرفته باشد:

```env
VITE_ENABLE_DEMO_MODE=true
```

اگر این متغیر تنظیم نشده باشد یا مقدار دیگری داشته باشد، برنامه باید API واقعی Laravel را استفاده کند.

## استفادهٔ مجاز

| محیط | مقدار پیشنهادی |
|---|---|
| سیستم توسعه برای نمایش نمونه | `VITE_ENABLE_DEMO_MODE=true` |
| staging متصل به API واقعی | تنظیم‌نکردن متغیر یا `false` |
| production | تنظیم‌نکردن متغیر یا `false` |

## هشدار امنیتی

demo mode نباید برای تست پرداخت، سفارش واقعی، اطلاعات مشتری، نقش ادمین، OTP پیامکی یا درگاه پرداخت استفاده شود. داده‌های ساختگی ممکن است در `localStorage` مرورگر ذخیره شوند و فقط برای نمایش محلی مناسب‌اند.

## build

متغیرهای `VITE_*` هنگام build در دارایی‌های فرانت وارد می‌شوند. پیش از اجرای `pnpm build` برای deployment، مطمئن شوید `VITE_ENABLE_DEMO_MODE` فعال نیست. برای تغییر این مقدار در production، build جدید تولید و جایگزین کنید.
