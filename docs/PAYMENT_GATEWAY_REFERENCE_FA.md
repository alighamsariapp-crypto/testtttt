# یادداشت فنی درگاه زرین‌پال

این پروژه هنوز فاقد شناسهٔ پذیرندگی و تنظیمات عملیاتی زرین‌پال است؛ بنابراین درگاه واقعی نباید بدون پیکربندی و آزمون sandbox فعال شود.

طبق مستندات رسمی، جریان پرداخت زرین‌پال شامل سه مرحله است: ایجاد درخواست پرداخت با `merchant_id`، مبلغ، `callback_url` و توضیح؛ انتقال خریدار با `authority` برگشتی؛ و سپس تأیید تراکنش پس از بازگشت کاربر، مشروط به وضعیت `Status=OK`. مبلغ تأیید باید از رکورد سمت سرور خوانده شود، نه از درخواست مرورگر. کدهای تأیید `100` و `101` هر دو نشان‌دهندهٔ پرداخت معتبر هستند؛ کد `101` بیانگر تأیید تکراری است.

منابع رسمی:

1. [مستندات درگاه پرداخت زرین‌پال](https://www.zarinpal.com/docs/paymentGateway/)
2. [اتصال به درگاه و نمونهٔ درخواست/تأیید](https://www.zarinpal.com/docs/paymentGateway/connectToGateway)
3. [راهنمای درخواست پرداخت در SDK](https://www.zarinpal.com/docs/sdk/nodejs/method/request)
4. [راهنمای تأیید پرداخت در SDK](https://www.zarinpal.com/docs/sdk/nodejs/method/verify)
